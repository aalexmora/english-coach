# Локальный просмотр прототипа

Открой `prototype.html` в браузере: это автономная сборка без сервера и зависимостей.
Исходники: `index.html`, `styles.css`, `profiles.js`, `conversation.js`, `app.js`.

Для локального просмотра из корня English Coach:

```sh
python3 -m http.server 8813 --bind 127.0.0.1 --directory prototypes/admin
```

Адрес: http://127.0.0.1:8813 . Все данные вымышлены. Черновики ДЗ живут только
до перезагрузки вкладки. API, авторизация и сохранение результатов не подключены.
Канонические требования: Obsidian English backlog, IDEA-004.

Выпуск прототипа `0.2.0-demo`: Александр и Катя имеют разные вымышленные
сценарии; профиль и фильтры указаны в URL. Версии UI/методики открывают журнал
изменений. Три режима темы сохраняют только внешний вид в localStorage;
разрешение грамматической практики Кати и черновики живут в памяти вкладки.
Переключатель не является авторизацией. Новые аккаунты не создаются.

После изменения исходников пересобери автономный файл:

```sh
python3 prototypes/admin/bundle.py
```
